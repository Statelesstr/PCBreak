# PCBreak

**Windows için ebeveyn kontrolü ve ekran süresi yönetimi.**

PCBreak; çocukların bilgisayar kullanım sürelerini, zorunlu molalarını ve haftalık kullanım saatlerini yönetmek için geliştirilmiş bir Windows uygulamasıdır.

### PCBreak V2

- Çoklu Windows kullanıcı desteği
- Kullanıcı bazlı kullanım süresi ve mola yönetimi
- Haftalık kullanım planı
- Otomatik kilitleme ve Tam Kilit modu
- +1 / +2 saat ebeveyn ek süresi
- Windows Service tabanlı arka plan kontrolü
- Çevrimdışı çalışma
- Windows 10 / 11 x64 desteği

Güncel kurulum paketini **Releases** bölümünden indirebilirsiniz.
